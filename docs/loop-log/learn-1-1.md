# 教科書形式(説明 → 確認問題) 1-1 の記録

役割を分けて進めた: 作る / 監修する / 初めて Python に触れる人(説明だけで試験に答える)。
試験は scripts/exam.mts で書き出し・採点(1回目の答えのみ、実行なし、ヒントなし)。合格は 90点以上。2回続けて未満なら中止。

| 回 | 内容 | 結果 |
|---|---|---|
| 作成 | 15節・確認問題20問(読む4問を追加)。未習チェック・例の結果・著作権 | テスト全件合格 x2、一致0件 |
| 監修 | 必ず直す1(lines の「」)、直したほうがよい6、好み多数 | 全部反映。テスト x2 合格 |
| 試験1 | 初めての人が20問に回答 | 100点(20/20) |
| 改善 | 試験でつまずいた10か所(かっこ内の空白、エラーの見た目、小数第1位 など)を説明に追加 | (下に追記) |
| 改善の結果 | テスト 1760件 x2 合格、一致0件 | 合格 |
| 試験2 | 最終版を別の「初めての人」が回答 | 100点(20/20)。未習の記号・言葉 0 件と回答 |
| 残り | round の .5 の決まり、エラー表示の <exec>/<module>、マイナスの % が説明不足との声(解答には影響なし) | 全章へ広げるときに直す |

# 3-1 辞書（教科書に作り直し）

- 教材の見出しの順に 11 節。説明と問題の1対は 21 個。教材の練習2つは作り直した問題（l31-roll / l31-group）を演習問題に。
- 古い explain の文章を、1つの考え方ごとのまとまりに分け直して教科書に移した。topics と explain は空。
- 1対にするため、読む問題を 4 個追加: r31-key, r31-del, r31-in, r31-keys。
- l31-roll の判定を変えた: range（3-2 で習う）を使わず、for name in names と names.index(name) で書く形に（教材の練習と同じ道具）。test / expect は同じ。課題文に「同じ名前は入っていない」を足した。
